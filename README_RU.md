# 🕒 Telegram-бот для управления дедлайнами и учебными задачами

Асинхронный Telegram-бот, спроектированный для мониторинга академических дедлайнов, трекинга вех учебных проектов и автоматического пуш-уведомления пользователей о приближающихся сроках сдачи. Бот поддерживает как персональный режим тайм-менеджмента, так и интеграцию в групповые чаты для синхронизации работы команд.

## 🛠️ Используемый стек и возможности
*   **Язык и библиотеки:** Python 3 + `aiogram`.
*   **Архитектура данных:** Структурированное отслеживание контекста пользователей и журналов задач.
*   **Ключевой функционал:**
    *   Добавление, просмотр, редактирование и удаление активных дедлайнов с валидацией временных меток.
    *   Поддержка групповых чатов для совместного ведения командных проектов или синхронизации старост с одногруппниками.
    *   Автоматическая очередь напоминаний о критических сроках завершения тасок.

## 📁 Структура исходного кода

*   `/uni_bot` — Основной пакет приложения Python, содержащий хэндлеры команд, конечные автоматы состояний и бизнес-логику бота.
*   `requirements` — Перечень внешних библиотек и пакетов зависимостей, необходимых для развертывания проекта.
